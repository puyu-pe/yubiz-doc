# 12.3 Anular una preventa

<a id="84-anular-una-preventa"></a>

Anule una preventa que no debe continuar.

## Cómo acceder

1. En la barra lateral, abra **Preventa**.
2. Seleccione **Preventas**.
3. Seleccione la preventa para abrirla antes de anularla.

## Pasos

1. Revise cliente, productos, cantidades y estado.
2. Complete el motivo cuando la pantalla lo solicite.
3. **Antes de confirmar,** deténgase si la preventa ya se convirtió o no corresponde al pedido que anulará.
4. Confirme la anulación y vuelva a la lista.

## Compruebe el resultado

Compruebe que la preventa muestra el estado de anulación.
