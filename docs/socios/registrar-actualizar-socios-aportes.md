# 9.1 Registrar y actualizar socios y aportes

Registre o actualice los datos visibles de un socio y consulte la lista de aportes configurados.

## Cómo acceder

1. En la barra lateral, abra **Socios**.
2. Seleccione **Gestion de Socios**.

## Pasos

1. Para crear un socio, seleccione **Añadir Socio**.
2. Complete **Nombre**, **Aporte**, **Porcentaje** y **Color**. Los cuatro datos son requeridos; **Aporte** y **Porcentaje** aceptan valores numéricos.
3. Revise los valores antes de confirmar. El campo **Color** inicia con un valor propuesto que puede cambiar.
4. Para actualizar un socio, localice su fila, abra la edición disponible y confirme los cambios.
5. Use **Lista de Aportes** para consultar los aportes del socio seleccionado.
6. Seleccione **Exportar** solo después de revisar que la lista contiene los socios que desea incluir.

## Compruebe el resultado

La tabla muestra el socio con **Nombre**, **Aporte**, **Porcentaje** y **Color**. Esta guía no valida distribución de utilidades ni cálculos financieros.
