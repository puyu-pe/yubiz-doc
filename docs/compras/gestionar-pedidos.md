Localice un pedido, actualícelo mientras su estado lo permita y use las acciones de comunicación disponibles.

## Cómo acceder

1. En la barra lateral, abra **Compras**.
2. Seleccione **Pedidos**.
3. Seleccione el pedido para abrirlo.

## Pasos

1. Filtre por proveedor, fecha, documento o estado y abra el pedido.
2. Revise sus productos, cantidades y total. Actualice los datos necesarios y guarde mientras el pedido no esté **COMPRADO** ni **ANULADO**.
3. Use las acciones de impresión, réplica o correo que estén disponibles para el pedido revisado.
4. Antes de enviar correo, compruebe destinatario y contenido; no lo intente si el pedido está **ANULADO**.

## Compruebe el resultado

Compruebe que el pedido conserva los cambios y que la acción de impresión, réplica o correo muestra el resultado disponible.
