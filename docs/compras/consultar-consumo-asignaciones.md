# 10.3 Consultar consumo de asignaciones

Consulte el consumo asociado a las asignaciones presupuestarias y exporte el resultado cuando lo necesite.

## Cómo acceder

1. En la barra lateral, abra **Presupuesto**.
2. Seleccione **Consumos de asignaciones**.

## Pasos

1. Revise la **Lista de consumos de asignaciones presupuestarias** y use los filtros de la tabla para delimitar la consulta.
2. Si necesita ajustar la vista, abra el menú de acciones de tres puntos y use **Editar columnas**, **Limpiar filtros** o **Restablecer columnas**.
3. Compruebe que las filas y los filtros mostrados corresponden a la consulta que necesita.
4. Para exportar el resultado actual, abra el menú de acciones y seleccione **Generar EXCEL**.

## Compruebe el resultado

La lista muestra los consumos de asignaciones que corresponden a los filtros aplicados y no ofrece una acción para crear consumos manualmente.
