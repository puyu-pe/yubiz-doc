# 7.3 Anular un pedido de compra

<a id="63-anular-un-pedido-de-compra"></a>

Anule un pedido que ya no debe continuar antes de convertirlo o notificarlo.

## Cómo acceder

1. En la barra lateral, abra **Compras**.
2. Seleccione **Pedidos**.
3. Seleccione el pedido para abrirlo antes de anularlo.

## Antes de empezar

- Compruebe que el pedido no esté **COMPRADO** ni **ANULADO**.

## Pasos

1. Revise proveedor, documento, productos y estado del pedido.
2. Seleccione **Anular** e ingrese el motivo si la pantalla lo solicita.
3. **Antes de confirmar,** deténgase si el pedido ya generó una orden o si no puede identificar el registro.
4. Confirme la anulación y vuelva a la lista.

## Compruebe el resultado

Compruebe que el pedido muestra estado **ANULADO** y que ya no ofrece acciones incompatibles.
