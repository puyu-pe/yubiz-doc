# 7.14 Anular un gasto

<a id="74-anular-un-gasto"></a>

Anule un gasto identificado cuando no deba seguir vigente.

## Cómo acceder

1. En la barra lateral, abra **Compras**.
2. Seleccione **Gastos**.
3. Seleccione el gasto para abrirlo antes de anularlo.

## Pasos

1. Revise fecha, categoría, conceptos, total y estado.
2. Compruebe que el gasto no esté rechazado ni anulado.
3. **Antes de confirmar,** deténgase si el gasto no es el registro correcto o si el estado impide anularlo.
4. Confirme la anulación y consulte el gasto de nuevo.

## Compruebe el resultado

Compruebe que el gasto muestra el estado de anulación.
