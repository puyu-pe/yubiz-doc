# 13.2 Registrar y actualizar vendedores

Registre o actualice un vendedor y revise los establecimientos que se muestran en su lista.

## Cómo acceder

1. En la barra lateral, abra **Ventas**.
2. Seleccione **Gestión de vendedores**.
3. Seleccione el vendedor para abrirlo.

## Pasos

1. Al crear un vendedor, complete **Nombre**, **Usuario** y **Estado**. Los tres campos son obligatorios; **Apellido** puede completarse cuando corresponda.
2. Elija **Activo** o **Inactivo** en **Estado** y revise que **Usuario** no coincida con otro registro antes de guardar.
3. Guarde el formulario. Para actualizar, abra el vendedor existente, modifique los campos necesarios y vuelva a guardar.
4. Revise la lista: muestra **Nombre**, **Apellido**, **Usuario**, **Estado**, **Establecimientos** y **Actualizado**. Use el botón **Establecimientos** del vendedor cuando necesite cambiar sus asignaciones.

## Compruebe el resultado

Localice el vendedor por nombre o usuario y compruebe que aparece con el estado elegido. Revise la columna **Establecimientos** para confirmar si muestra las asignaciones activas o **Sin asignar**.

## Situaciones frecuentes

- **El usuario ya está registrado:** use un valor de **Usuario** que no pertenezca a otro registro antes de guardar.
