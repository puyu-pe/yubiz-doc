# 5.12 Registrar una salida de almacén

<a id="54-registrar-una-salida-de-almacen"></a>

Registre la salida de productos desde un almacén y compruebe que el movimiento contiene las unidades correctas.

## Cómo acceder

1. En la barra lateral, abra **Inventario**.
2. Seleccione **Crear salida de almacen**.

## Antes de empezar

- Tenga identificado el almacén de origen, el producto y la cantidad que saldrá.
- Si el producto usa series, tenga identificadas las series que se retirarán.

## Pasos

1. Seleccione el almacén de origen y revise la fecha del movimiento.
2. Agregue el producto y complete la cantidad que saldrá.
3. Revise la cantidad disponible y asigne las series solicitadas, si corresponde.
4. Complete la observación solo cuando sea necesaria para identificar la salida.
5. **Antes de confirmar,** deténgase si el producto, la cantidad o el almacén no coinciden con la salida que realizará.
6. Seleccione **Registrar** para guardar el movimiento.

## Compruebe el resultado

Abra el movimiento o el kardex del producto y contraste el almacén, la cantidad retirada, la fecha y las series asignadas.
