# 4.1 Crear campañas de descuento y asignar productos

<a id="121-crear-campanas-de-descuento-y-asignar-productos"></a>

Cree una campaña y agregue o retire productos asociados.

## Cómo acceder

1. En la barra lateral, abra **Fidelización de clientes**.
2. Seleccione **Crear campaña de descuento**.
3. Para consultar una campaña, abra Fidelización de clientes > Campañas y selecciónela.

## Pasos

1. Complete los datos que muestra la creación de campaña y guarde.
2. Abra la campaña, agregue los productos que correspondan y guarde.
3. **Antes de retirar un producto,** compruebe campaña y producto seleccionados.
4. Use la acción disponible para retirarlo.

## Compruebe el resultado

Compruebe que la campaña muestra los productos asociados.
