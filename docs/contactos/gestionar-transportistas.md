Registre un transportista o actualice sus datos de identificación y vehículo antes de seleccionarlo en un traslado.

## Cómo acceder

1. En la barra lateral, abra **Contactos**.
2. Seleccione **Transportistas**.
3. Seleccione un transportista para actualizarlo.

## Antes de empezar

- Tenga nombre, RUC y los datos de vehículo o licencia que solicite el formulario.

## Pasos

1. Busque por nombre o RUC para comprobar que el transportista no está registrado.
2. Agregue el transportista o abra el registro existente.
3. Complete nombre, apellido, RUC, marca o placa y licencia de conducir; agregue certificado de inscripción o dueño cuando correspondan.
4. Revise que los datos del transportista y vehículo coinciden y guarde.
5. Para actualizar, cambie solo los datos necesarios y guarde nuevamente.

## Compruebe el resultado

Vuelva a la lista y compruebe que el transportista se identifica por nombre, RUC y datos de vehículo.
