# 8.4 Registrar y actualizar entidades financieras

Mantenga las entidades financieras que aparecen en la lista de contactos.

## Cómo acceder

1. En la barra lateral, abra **Contactos**.
2. Seleccione **Entidades Financieras**.

## Pasos

1. Para crear una entidad, seleccione **Añadir**.
2. Complete **Tipo de Entidad** y **Nombre**, que son requeridos. Puede agregar **Descripción** y elegir **Estado** cuando corresponda; el estado ofrece **Activo** e **Inactivo**.
3. Confirme el registro con la acción disponible.
4. Para actualizarla, localice la fila por **Tipo de Entidad** o **Nombre**, seleccione **Editar** y confirme los cambios.
5. Para retirar una entidad, localice la fila y seleccione **Eliminar**.
6. **Advertencia:** esta acción la deja inactiva. Deténgase si no puede confirmar que es el registro correcto o si la pantalla indica que no permite eliminarlo.
7. Confirme el retiro únicamente después de esa revisión.

## Compruebe el resultado

La lista refleja el **Tipo de Entidad**, **Nombre** y **Estado** registrados; tras el retiro, verifique el estado que muestra la consulta.
