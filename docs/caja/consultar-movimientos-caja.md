# 2.13 Consultar movimientos de caja

Revise por separado los ingresos y egresos de caja para un establecimiento, usuario y período determinados.

## Cómo acceder

1. En la barra lateral, abra **Ventas**.
2. Abra **Reportes** y seleccione **Ingreso egreso dinero**.

## Pasos

1. Elija **Establecimiento** y, si corresponde, **Usuario**.
2. Indique **Desde** y **Hasta** para delimitar el período.
3. Seleccione **Buscar**.
4. Revise las secciones **Ingresos**, **Egresos**, **Detalle comercial**, **Saldo inicial**, **Operaciones manuales** y **Resumen por entregar**.

## Compruebe el resultado

Las secciones muestran los movimientos y resúmenes correspondientes a los filtros aplicados.
