# 2.14 Registrar saldo inicial de caja

Registre el saldo inicial desde el reporte de ingresos y egresos cuando corresponda iniciar la operación de caja.

## Cómo acceder

1. En la barra lateral, abra **Ventas**.
2. Abra **Reportes** y seleccione **Ingreso egreso dinero**.

## Antes de empezar

- Defina el **Establecimiento** y el período sobre los que registrará el saldo.

## Pasos

1. En los controles de operación manual de **Ingreso egreso dinero**, seleccione **Registrar saldo inicial** para abrir el formulario disponible.
2. Complete **Importe**, **Método** y **Fecha y hora**. **Observación** es opcional; la fecha y hora inicia con el momento actual.
3. **Advertencia:** el saldo inicial afecta la lectura posterior de caja y solo admite un registro por día, establecimiento y usuario. Deténgase si el importe o el contexto no corresponden al inicio que desea registrar.
4. Seleccione **Guardar**.

## Compruebe el resultado

Vuelva a consultar el reporte y compruebe que el importe aparece en la sección **Saldo inicial** para el contexto seleccionado.
