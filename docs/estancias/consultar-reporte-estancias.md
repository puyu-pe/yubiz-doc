# 11.7 Consultar el reporte de estancias

Consulte el resumen de estados de estancia para un establecimiento, usuario y período.

## Cómo acceder

1. En la barra lateral, abra **Estancia**.
2. Seleccione **Reporte de estancias**.

## Pasos

1. Elija **Establecimiento** y, si corresponde, **Usuario**.
2. Indique **Desde** y **Hasta**.
3. Seleccione **Buscar**.
4. Revise **Resumen de estados** y la tabla con **Estado** y **Cantidad**.

## Compruebe el resultado

El resumen y la tabla muestran las cantidades de estancias agrupadas por estado para los filtros aplicados.
