# 11.5 Registrar y actualizar relaciones de estancia

Mantenga las relaciones disponibles para las estancias desde su pantalla específica.

## Cómo acceder

1. En la barra lateral, abra **Estancia**.
2. Seleccione **Relacion**.

## Pasos

1. Para crear una relación, seleccione **Añadir Relacion**.
2. Indique **Relacion**, que es el dato obligatorio. Puede completar **Descripcion** y seleccionar el **Estado**.
3. Revise el nombre de la relación antes de usar la acción de guardado del formulario. Al crearla, el estado inicial es **Activo**.
4. Para actualizar una relación, localice el registro y seleccione **Editar**. Modifique los datos necesarios, revíselos y use la acción de guardado.
5. Para eliminar una relación, seleccione **Eliminar** en el registro correspondiente. Confirme solo después de comprobar el nombre del registro que se retirará.

## Compruebe el resultado

La lista muestra la **Relacion** y el **Estado** del registro creado o actualizado; una relación eliminada deja de aparecer en la lista.
