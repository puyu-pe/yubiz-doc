# 11.4 Registrar y actualizar tarifas de estadía

Mantenga las tarifas de estadía desde su pantalla específica.

## Cómo acceder

1. En la barra lateral, abra **Estancia**.
2. Seleccione **Tarifas de estadía**.

## Pasos

1. Para crear una tarifa, seleccione **Añadir Tarifa de estadía**.
2. Complete los campos obligatorios: **Producto**, **Tarifa**, **Duración** y **Unidad**. La unidad de duración ofrece **Minuto**, **Hora** y **Día**; el formulario propone una unidad inicial según la configuración disponible.
3. Seleccione el **Estado** que corresponda; al crear una tarifa, el valor inicial es **Activo**.
4. Revise que el producto no esté asociado a otra tarifa y que la duración y su unidad sean correctas. Luego use la acción de guardado del formulario.
5. Para actualizar una tarifa, localice el registro y seleccione **Editar**. Ajuste los mismos campos, revíselos y use la acción de guardado.
6. Para eliminar una tarifa, seleccione **Eliminar** en el registro correspondiente. Confirme solo después de verificar el producto y la tarifa que se retirarán.

## Compruebe el resultado

La lista muestra **Producto**, **Tarifa**, **Duración**, **Unidad** y **Estado** para el registro creado o actualizado; una tarifa eliminada deja de aparecer en la lista.
