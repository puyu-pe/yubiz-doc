# Compras, gastos y caja

Organice compras, gastos, caja y reportes financieros desde un mismo recorrido operativo.

## Recorrido sugerido

1. Inicie en [Compras](../../compras/index.md) para pedidos, órdenes y documentos.
2. Registre [Gastos](../../gastos/index.md) y revise [Caja](../../caja/index.md) según la operación.
3. Consulte [Reportes financieros](../../reportes/index.md) para pagos y deudas.
